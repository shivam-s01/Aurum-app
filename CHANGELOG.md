# Changelog

All notable changes to Aurum Music are documented here.

## [2.3.1] — 2026-08-05

### Added
- Battery-optimized playback engine improvements
- Persistent disk cache for streamed songs (instant replay, faster seeking)
- Duck-based audio focus handling (fewer playback interruptions)

### Fixed
- Cold-start cache jank on home feed
- Up-next queue ordering and race conditions
- Full player UI: artist text visibility, pill styling, button colors
- Search relevance threshold tuning
- Queue deduplication

### Changed
- Version scheme reset to reflect app maturity (previously 1.0.0)
